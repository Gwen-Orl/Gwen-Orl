## 🔭 Projet universitaire 

### ✈️ SAE VolConnect

Dans le cadre d'un projet universitaire, j'ai développé une application permettant aux utilisateurs de consulter et de rechercher des informations liées aux aéroports, aux compagnies aériennes ou aux vols.
Chef de projet dans une équipe de 3 étudiants.
Tâches effectuées : 

- Conception du MCD (Modèle Conceptuel de Données).
- Mise en place de l'API REST.
- Création des modèles avec SQLAlchemy.
- Réalisation des tests de couverture (coverage).
- Création d'une SPA en JS, reliée à l'API REST pour les opérations CRUD.
- Mise en place du suivi de projet ainsi que rédaction du README.

[Voir le projet](https://github.com/Wlacroix45/SAE_VolConnect)
